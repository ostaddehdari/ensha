# Ensha v0.24.2 — ENSHA-P1-S03-W02

این ورک تجربه تقویم منشی را برای شعبه‌ها، نمایش شمسی، ویرایش درون تقویم و منطقه زمانی کامل می‌کند.

## تغییرات اصلی

- فیلتر شعبه و شیوه ارائه به فیلترهای مشاور، موضوع و وضعیت افزوده شد.
- شعبه در ثبت دستی نوبت ذخیره می‌شود و منابع و شیفت‌های تقویم بر اساس همان شعبه محدود می‌شوند.
- ساعت انتخابی با منطقه زمانی مؤثر شعبه تفسیر و برای ذخیره به منطقه زمانی برنامه تبدیل می‌شود.
- API رویدادها ساعت محلی شعبه، تاریخ شمسی، نام شعبه و منطقه زمانی را برمی‌گرداند.
- کلیک روی نوبت، فرم ویرایش شعبه، مشاور، تاریخ، ساعت و مدت را داخل تقویم باز می‌کند.
- نوبت‌های قدیمی بدون شعبه همچنان قابل نمایش، Drag و Resize هستند.

## معیار پذیرش

- فیلتر شعبه فقط نوبت‌ها و مشاوران همان شعبه را نشان دهد.
- ثبت دستی، `branch_id` را روی اسلات و نوبت ذخیره کند.
- ساعت محلی یک شعبه غیر از تهران بدون جابه‌جایی ناخواسته نمایش داده شود.
- تاریخ شمسی و منطقه زمانی در تقویم و فرم ویرایش دیده شوند.
- ویرایش داخل تقویم از همان کنترل تداخل W01 استفاده کند و پاسخ 409 را نمایش دهد.
- آزمون اختصاصی و کل مجموعه Application پاس شوند.
