# Ensha v0.23.0 — Stage 11

Stage 11 چرخه عملیاتی مرکز را با گزارش مالی، ماه شمسی، حقوق کارکنان و خروجی واقعی Excel تکمیل می‌کند.

## قابلیت‌های اصلی

- جدول مالی هر مشاوره شامل تعرفه، تخفیف، مبلغ نهایی، وصول، مانده و سهم‌ها.
- جمع‌بندی نوبت‌ها و وصول واقعی دفتر تراکنش بر اساس ماه شمسی و تفکیک مشاور.
- گزارش بدهکاران، صندوق‌های روزانه و تسویه مشاوران.
- داشبورد مستقل مدیر مرکز و مسئول مالی با شاخص‌های ماه شمسی جاری.
- محاسبه کارکرد از حضور و غیاب: روز کاری، ساعات، تأخیر، خروج زودتر، اضافه‌کار و کسری.
- محاسبه حقوق بر اساس قواعد ثابت، ساعتی، شیفتی، ثابت+اضافه‌کار و ترکیبی.
- ساخت و قفل Snapshot دوره حقوق برای جلوگیری از تغییر سوابق گذشته.
- خروجی استاندارد XLSX برای مالی، ماهانه، مشاوران، بدهکاران، صندوق، تسویه و حقوق.
- ثبت حسابرسی همه خروجی‌ها همراه فیلتر، تعداد سطر و SHA256 فایل.

ورودی‌های تاریخ با تقویم شمسی عمومی سایت انتخاب می‌شوند و گروه‌بندی ماهانه نیز بر اساس ماه شمسی است.
