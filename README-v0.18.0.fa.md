# Ensha v0.18.0 — Stage 06

هستهٔ مشترک نوبت‌دهی، قیمت‌گذاری و دسترس‌پذیری برای منشی و مشاور. نمای روزانهٔ چندمشاوره با DayPilot Lite، ثبت سریع مراجع، پروندهٔ Draft، درخواست مرخصی، برنامهٔ هفتگی، فرم پویای تکمیل پرونده و حضور کارکنان اضافه شده‌اند.

این بسته از نصب v0.16.0 یا v0.17.0 پشتیبانی می‌کند؛ در مسیر v0.16.0، migration مرحلهٔ 05 نیز همراه Stage 06 اعمال می‌شود. نصب‌کننده پیش از تغییر، backup فایل‌ها و دیتابیس می‌گیرد و روی شکست rollback می‌کند.

الزام‌ها: PHP 8.3+، Composer، Redis برای قفل رزرو، سرویس ensha-web، دیتابیس و تنظیمات سالم `.env`. افزونهٔ WordPress و API عمومی هنوز منتشر نشده‌اند؛ فقط هسته برای استفادهٔ بعدی آماده شده است. تمام قیمت‌ها مطابق نسخه‌های قبلی در واحد IRR ذخیره می‌شوند.

قبل از نصب واقعی، روی کپی staging با دادهٔ مشابه تولید اجرا و آزمون‌های Feature را مرور کنید. اجرای آزمون Laravel در محیط ساخت بسته ممکن نبود.
