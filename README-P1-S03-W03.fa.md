# Ensha v0.24.3 — ENSHA-P1-S03-W03

این ورک پذیرش واقعی مرورگر برای تقویم منشی را ثبت و قابل تکرار می‌کند. کد عملیاتی تقویم در W01 و W02 تکمیل شده بود؛ W03 صحت آن را روی سایت زنده با حساب منشی و داده DEMO ثابت می‌کند.

## موارد تکمیل‌شده

- ساخت ۱۶ اسلات واقعی برای شعبه، خدمت و مشاور منتخب.
- ثبت نوبت DEMO و نمایش آن در تقویم.
- آزمون فیلتر شعبه و مشاور.
- Drag واقعی و ذخیره تغییر ساعت.
- Resize واقعی و ذخیره مدت جدید.
- ایجاد تعارض کنترل‌شده و مشاهده رد شدن تغییر با رفتار 409.
- ثبت وضعیت نهایی نوبت برای بازبینی مالک پروژه.
- افزودن Playwright Spec ایمن که فقط با پرچم صریح اجرای زنده فعال می‌شود.
