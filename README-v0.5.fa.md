# انشا ۰.۵ — فرم‌ساز پروفایل

نیازمند نصب نسخهٔ ۰.۴ و PHP 8.3 یا بالاتر.

## امکانات

- چهار تب مستقل «همه»، «منشی»، «مشاور» و «مراجعه‌کننده». فیلدهای «همه» در فرم همهٔ کاربران نمایش داده می‌شوند.
- چهار فیلد ثابت نام، نام خانوادگی، تلفن و کد ملی، که برای هویت و ورود کاربرد دارند و حذف یا جابه‌جا نمی‌شوند.
- فهرست ۱۷ نوع آیتم؛ کلیک یا کشیدن برای افزودن، ویرایش تنظیمات در ستون چپ، کلون، حذف و مرتب‌سازی در ستون راست.
- ثبت پاسخ فیلدها در فرم ایجاد و ویرایش کاربران، اعتبارسنجی نوع/گزینه/الزامی در سرور، حفظ داده‌های فیلدهای دارای پاسخ هنگام حذف (غیرفعال‌سازی).
- ترتیب و تنظیمات در دیتابیس ذخیره می‌شوند. داده‌های قبلی و فیلدهای نسخهٔ ۰.۳/۰.۴ حفظ می‌شوند.

## انتقال و نصب

روی ویندوز در Git Bash:

```bash
cd ~/Downloads
scp -i ~/.ssh/id_ed25519_vps -P 2233 ensha-laravel-v0.5-profile-builder.zip root@5.61.27.185:/tmp/
ssh -i ~/.ssh/id_ed25519_vps -p 2233 root@5.61.27.185
```

پیش از نصب، یک نسخهٔ پشتیبان جداگانه از دیتابیس بگیرید. اسکریپت فقط از فایل‌های برنامه بکاپ می‌گیرد.

```bash
mkdir -p /tmp/ensha-v0.5
unzip -q /tmp/ensha-laravel-v0.5-profile-builder.zip -d /tmp/ensha-v0.5
bash /tmp/ensha-v0.5/ensha-base/deploy/update-v0.5.sh /tmp/ensha-v0.5/ensha-base /var/www/ensha
systemctl status ensha-web --no-pager
curl -i http://127.0.0.1:18850/up
```

فرم‌ساز: https://srun.ir/ensha/profile-fields

نکته: گزینهٔ پیش‌نمایش، چیدمان فیلدها را نشان می‌دهد؛ برای مشاهدهٔ نهایی در فرم کاربر، نقش موردنظر را در صفحهٔ ایجاد کاربر انتخاب کنید. فیلدهای «بارگذاری فایل» و «HTML سفارشی» در این نسخه نیستند، چون ذخیره‌سازی فایل و HTML نیازمند کنترل امنیتی مستقل است.
