# Ensha v0.16.0 — Stage 04 کامل

Stage 04 «تقویم Outlook منشی» را روی خط مبنای v0.15.0 فعال می‌کند.

## قابلیت‌ها

- تقویم RTL با نمایش روز، هفته و ماه
- ستون مستقل برای هر مشاور در نمای روز
- فیلتر مشاور، خدمت و وضعیت نوبت
- ایجاد نوبت در پنجرهٔ تقویم، فقط از اسلات آزاد Stage 03
- Drag & Drop و تغییر مدت نوبت؛ سرور فقط زمانی تغییر را می‌پذیرد که اسلات مقصد آزاد باشد
- پاسخ `409 Conflict` و بازگرداندن تقویم در تداخل‌ها
- نمایش فارسی تاریخ‌ها با `Intl` مرورگر، بدون تاریخ تعطیلات هاردکدشده

تقویم فقط پنل Laravel را مصرف می‌کند. Widgetهای WordPress/Elementor در آینده تنها از REST Proxy امن WordPress به Laravel استفاده خواهند کرد و اتصال مستقیم به MySQL ندارند.
