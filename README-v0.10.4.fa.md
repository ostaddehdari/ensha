# Ensha Stage 00 / v0.10.4

این نسخه خط مبنای پایدار ادامه توسعه Ensha است. نصب فقط روی یک نصب موجود Ensha در مسیر پیش‌فرض `/var/www/ensha` انجام می‌شود.

نصب‌کننده پیش از تغییر، از فایل‌های برنامه، `.env`، تنظیم nginx، واحد systemd و پایگاه داده نسخه پشتیبان می‌گیرد. اگر نصب، Migration یا Health Check شکست بخورد، Rollback خودکار اجرا می‌شود.

برای نصب از فایل اصلی بسته و اسکریپت `install.sh` استفاده کنید. خروجی کامل نصب در `/var/log/ensha-stage00-v0.10.4.log` ثبت می‌شود.
