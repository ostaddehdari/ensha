# انشا ۰.۶ — فرم‌ساز پروفایل با ذخیرهٔ یک‌مرحله‌ای

این بسته برای ارتقای نسخهٔ ۰.۵ است و PHP 8.3 یا جدیدتر لازم دارد.

## تغییرات

- بوم سمت راست به‌صورت انعطاف‌پذیر از ستون ابزار سمت چپ پهن‌تر است.
- چهار تب بدون بارگذاری دوبارهٔ صفحه جابه‌جا می‌شوند. افزودن، کلون، حذف، ویرایش و تغییر ترتیب فقط در پیش‌نویس مرورگر انجام می‌شود.
- دکمهٔ «ذخیره فرم» همهٔ تغییرات هر چهار تب را با یک درخواست AJAX و یک تراکنش دیتابیس ثبت می‌کند. خروج با تغییرات ذخیره‌نشده هشدار می‌دهد.
- گزینه‌های انتخابی هر کدام دو ورودی «برچسب نمایشی» و «مقدار ذخیره‌شونده» و دکمه حذف ردیف دارند. مقادیر قدیمی از نسخهٔ ۰.۵ به‌صورت برچسب/مقدار یکسان خوانده می‌شوند.
- فیلدهای دارای پاسخ هنگام حذف از بوم، بایگانی می‌شوند؛ پاسخ‌ها باقی می‌مانند. نوع و کلید فیلد دارای پاسخ یا مقدار گزینه‌های آن قابل تغییر نیست، ولی برچسب‌ها و ترتیب قابل ویرایش‌اند.
- ذخیرهٔ هم‌زمان در پنجرهٔ دیگر تشخیص داده می‌شود؛ در این حالت فرم باید دوباره بارگذاری شود.

## آپلود در Git Bash ویندوز

فایل ZIP را در Downloads ذخیره کنید:

```bash
cd ~/Downloads
scp -i ~/.ssh/id_ed25519_vps -P 2233 ensha-laravel-v0.6-ajax-profile-builder.zip root@5.61.27.185:/tmp/
ssh -i ~/.ssh/id_ed25519_vps -p 2233 root@5.61.27.185
```

## نصب روی سرور

ابتدا از دیتابیس انشا نسخهٔ پشتیبان بگیرید؛ اسکریپت ارتقا فقط از فایل‌های برنامه پشتیبان می‌گیرد.

```bash
mkdir -p /tmp/ensha-v0.6
unzip -q /tmp/ensha-laravel-v0.6-ajax-profile-builder.zip -d /tmp/ensha-v0.6
bash /tmp/ensha-v0.6/ensha-base/deploy/update-v0.6.sh /tmp/ensha-v0.6/ensha-base /var/www/ensha
systemctl status ensha-web --no-pager
curl -i http://127.0.0.1:18850/up
cd /var/www/ensha && php artisan route:list --path=profile-fields
```

سپس https://srun.ir/ensha/profile-fields را با Ctrl+F5 باز کنید.
