# Ensha v0.13.0 — Stage 02 / Work 02

این نسخه روی v0.12.0 نصب می‌شود و هستهٔ پرونده‌های مشاوره را اضافه می‌کند.

## جدول‌ها

- `cases`: پروندهٔ عملیاتی مراجع با وضعیت و اولویت.
- `case_assignments`: تخصیص پرونده به کارکنان با نقش و وضعیت تخصیص.
- `case_status_histories`: تاریخچهٔ قابل ردیابی تغییر وضعیت.

## مسیرهای اصلی

- `/cases`
- `/cases/create`
- `/cases/{case}`

در این Work، محتوای محرمانهٔ جلسه عمداً وارد پرونده نشده است و در Work 04 طراحی خواهد شد.
