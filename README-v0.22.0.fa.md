# Ensha v0.22.0 — Stage 10

این نسخه سهم مرکز و مشاور را به یک دفتر نسخه‌دار و قابل حسابرسی تبدیل می‌کند و دوره کامل تسویه مشاور را می‌سازد.

## قابلیت‌ها

- قانون درصدی یا مبلغ ثابت در سطح مرکز، موضوع، مشاور یا ترکیب موضوع و مشاور.
- نسخه‌بندی تاریخ‌دار قوانین و اولویت خودکار قانون اختصاصی بر قانون عمومی.
- ثبت Snapshot تغییرناپذیر سهم مرکز و مشاور هنگام تکمیل هر جلسه.
- محاسبه سهم قابل تسویه فقط بر مبنای وجه وصول‌شده؛ پرداخت مرحله‌ای در دوره‌های بعدی تکمیل می‌شود.
- پیش‌نویس، تأیید مدیریتی، ثبت پرداخت و لغو کنترل‌شده تسویه.
- کسورات، پاداش، شماره یکتای تسویه و اقلام ریز هر نوبت.
- صفحه «تسویه‌های من» برای مشاور با محدودیت کامل به داده‌های خودش.

قانون پیش‌فرض هر مرکز ۷۰٪ برای مشاور است و مدیر می‌تواند نسخه جدید بسازد. تغییر قانون یا تعرفه، Snapshot جلسات قبلی را تغییر نمی‌دهد.
