# Ensha v0.17.0 — Stage 05 کامل

Stage 05 «عملیات منشی و مشاورهٔ تلفنی» را فعال می‌کند:

- پذیرش مراجع، صف انتظار، شروع و پایان جلسه، ثبت عدم مراجعه
- لغو، جابه‌جایی با ایجاد نوبت جدید و تاریخچهٔ جابه‌جایی، و لیست انتظار
- ثبت تماس تلفنی با زمان، نتیجه و یادداشت مشاور
- ساخت صف یادآوری پیامکی و گزارش روزانهٔ منشی

پیامک‌ها در این نسخه صرفاً در صف ثبت می‌شوند. ارسال واقعی به Provider خارجی نیاز دارد و بدون اتصال معتبر انجام نمی‌شود.
