# Ensha v0.24.1 — ENSHA-P1-S03-W01

این ورک کنترل یکپارچه منابع نوبت را برای ساخت، جابه‌جایی و تغییر مدت جلسه فعال می‌کند.

## تغییرات اصلی

- قفل‌های Redis برای مشاور، اسلات و مخزن اتاق‌ها با ترتیب ثابت گرفته می‌شوند تا درخواست‌های هم‌زمان به رزرو ناسازگار منجر نشوند.
- قواعد شیفت، استثنای برنامه، مرخصی، تعطیلی، فاصله استراحت خدمت و تداخل مراجع و مشاور در یک سرویس مشترک اجرا می‌شوند.
- اتاق بر اساس مرکز، شعبه، موضوع خدمت و ظرفیت انتخاب می‌شود و رزرو و جابه‌جایی از همان کنترل ظرفیت استفاده می‌کنند.
- ظرفیت اسلات دستی از ظرفیت خدمت گرفته می‌شود و رزرو گروهی تا ظرفیت خدمت و اتاق ادامه پیدا می‌کند.
- Resize اسلات دارای چند نوبت رد می‌شود تا زمان نوبت‌های یک اسلات گروهی ناسازگار نشود.
- جابه‌جایی و Resize در تاریخچه وضعیت نوبت با اطلاعات اسلات قدیم و جدید ثبت می‌شوند.

## معیار پذیرش

- ساخت نوبت در فاصله استراحت مشاور با پاسخ 409 رد شود.
- Resize به بازه اشغال‌شده مشاور یا اتاق با پاسخ 409 رد شود.
- جابه‌جایی به مرخصی یا استثنای unavailable با پاسخ 409 رد شود.
- اسلات گروهی دستی ظرفیت خدمت و اتاق را رعایت کند.
- مجموعه کامل تست‌های Application و Health Check پس از نصب پاس شوند.
