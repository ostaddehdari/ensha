# Ensha v0.11.0 — مرکز، کارکنان و دسترسی‌ها

این نسخه Stage 01 را از خط مبنای امن v0.10.4 تکمیل می‌کند.

## قابلیت‌های اصلی

- مرکز دارای منطقه زمانی و تنظیمات عملیاتی ساختاریافته است.
- هر مرکز یک یا چند شعبه و دقیقاً یک شعبه پیش‌فرض دارد.
- هر انتساب نقش مرکز‌محور می‌تواند به یک شعبه متصل شود.
- پرونده همکاری برای همه کارکنان غیرمراجع قابل مدیریت است.
- شعب، تنظیمات و کارکنان مجوزهای مشاهده و مدیریت جداگانه دارند.
- منشی به‌صورت پیش‌فرض مشاهده‌گر شعب، تنظیمات و کارکنان است؛ مدیر مرکز امکان مدیریت دارد.
- انتخاب نقش فعال، شعبه را نیز در زمینه نشست اعمال می‌کند.

## نسخه و مسیر ارتقا

- نسخه مبدأ: `0.10.4`
- نسخه مقصد: `0.11.0`
- نصب‌کننده: `install-stage01.sh`
- بررسی: `verify-stage01.sh`
- Rollback: `deploy/rollback-v0.11.0.sh`

نصاب پیش از تغییر برنامه از فایل‌ها و دیتابیس Backup معتبر می‌گیرد و در خطای Migration، Verify، تست، سرویس یا Health Check به‌صورت خودکار بازمی‌گردد.
