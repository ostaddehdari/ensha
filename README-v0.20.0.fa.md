# Ensha v0.20.0 — Stage 08

این نسخه ضبط امن صوت جلسه و مدیریت متن پیاده‌شده را به فضای کاری مشاور اضافه می‌کند.

## امکانات اصلی

- ثبت رضایت صریح شفاهی، کتبی یا دیجیتال پیش از فعال‌شدن ضبط.
- ضبط مستقیم میکروفن در مرورگر با نمایش زمان و وضعیت بارگذاری.
- بارگذاری قطعه‌ای برای جلوگیری از شکست فایل‌های طولانی.
- محدودیت پیش‌فرض ۲۵۰ مگابایت و حداکثر ۱۲ ساعت برای هر ضبط.
- ذخیره خارج از مسیر عمومی و رمزگذاری جریانی با XChaCha20-Poly1305.
- بررسی SHA-256 فایل رمزگذاری‌شده پیش از هر پخش.
- پخش امن فقط برای مشاور همان نوبت یا Super Admin.
- ثبت ممیزی رضایت، شروع، پایان، پخش، حذف و متن‌سازی.
- ثبت دستی متن صوت، ذخیره پیش‌نویس و نهایی‌سازی قفل‌شده با هش محتوا.
- صف تبدیل خودکار صوت به متن برای سرویس‌های Whisper-compatible.
- سرویس مستقل `ensha-queue.service` برای پردازش کارهای بالینی.
- زمان بازپس‌گیری Jobهای طولانی Queue به ۱۲۰۰ ثانیه افزایش یافته تا پردازش صوت تکراری اجرا نشود.

## تفکیک دسترسی

- مشاور فقط ضبط‌های نوبت‌های خودش را ایجاد، پخش و متن‌گذاری می‌کند.
- مدیر مرکز فقط مجوز ممیزی فراداده ضبط را دارد و به محتوای صوت دسترسی پیش‌فرض ندارد.
- منشی هیچ مجوزی برای صوت و متن محرمانه جلسه دریافت نمی‌کند.

## تبدیل خودکار صوت به متن

ثبت و اصلاح دستی متن همیشه فعال است. برای فعال‌کردن تبدیل خودکار، متغیرهای زیر در `.env` تنظیم می‌شوند:

```dotenv
ENSHA_TRANSCRIPTION_URL=https://example.test/v1/audio/transcriptions
ENSHA_TRANSCRIPTION_TOKEN=
ENSHA_TRANSCRIPTION_MODEL=whisper-1
ENSHA_TRANSCRIPTION_LANGUAGE=fa
ENSHA_TRANSCRIPTION_PROVIDER=whisper-compatible
ENSHA_TRANSCRIPTION_TIMEOUT=900
```

پس از تغییر `.env` باید `php artisan config:cache` و `systemctl restart ensha-queue.service` اجرا شود.
